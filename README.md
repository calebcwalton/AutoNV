# AutoNV

LLM's have the potential to act as optimizer for systems that are usually ill-formed for classical optimization protocols. The goal of this repo is to build out a simulation toolbox, that allows for the LLM to recursively test hypotheses regarding a real quantum platform, and validate the proposed underlying Hamiltonian. The hope, is that an LLM can decipher the solution on a timescale much faster then a human researcher could.

Future extensions to the problem are to look into gate optimization based on the discovered Hamiltonian.
